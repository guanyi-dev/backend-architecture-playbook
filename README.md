## Guiding Principles

This repository emphasizes **understanding over memorization**.

For every topic, I aim to answer questions such as:

- What problem does this solve?
- Why was this technology chosen?
- What are the trade-offs?
- When should it be used—or avoided?
- How does it apply to real production systems?
